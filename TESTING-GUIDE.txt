PART 5 — COMMON PROBLEMS (QUICK FIX)
================================================================================

Problem: Login 500 / ECONNREFUSED 5000
  → Backend band. backend → npm run dev

Problem: Faculty API 500 "Prisma model not available"
  → Backend restart. Agar phir bhi: stop backend → npx prisma generate → npm run dev

Problem: Teacher ko koi batch nahi
  → Admin se batch pe Instructor assign karo (teacher user)

Problem: Demo Scheduled status set nahi hota grid se
  → Expected. Demo tab se Record Demo karo

Problem: Old user login after reset-qa fail
  → Tokens/users wipe. Naye cheat-sheet emails use karo

Problem: Masters empty after reset
  → Galat reset use kiya. db:reset-qa masters rakhta hai.
     Full wipe sirf db:reset (avoid)
